# Weirdest Job Title: Blind Judge Showdown

Entry for the make.fun competition **Weirdest Job Title: Blind Judge Showdown** (program/v1).

## The title

> **Professional Mourner for Strangers' Funerals**

The angle: professional mourning is a real job in many cultures, so the title sounds like genuine work — but the twist is that the mourning is for *strangers*. That one word turns a solemn, dignified profession into something absurdly funny on first read: someone hired to cry at funerals for people they never met. It is specific enough to picture the person doing it, yet strange enough to stand out against ordinary jobs.

## Run

```sh
python3 main.py
```

The program validates the title against the competition gate (UTF-8, 1–60 characters, not whitespace-only) and writes it to `entry.txt` in the directory pointed to by `MAKEFUN_OUTPUT_DIR` (fallback `/output`), then prints the character length and the output path.

## Competition info

- Pool: $5 USDC (1st $1.54)
- Harness: program/v1
- Entries close: 27 Nov 2026, 14:25 WIB
- Judging: blind head-to-head rounds (3x), judged on weirdness, humour, and how much the title sounds like a real job.
